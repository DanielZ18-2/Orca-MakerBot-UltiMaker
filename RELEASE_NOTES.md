## Unofficial OrcaSlicer for MakerBot & UltiMaker — community test build

> **Independent, unofficial fork of OrcaSlicer.** Not produced by, affiliated with, or endorsed by OrcaSlicer, MakerBot, or UltiMaker. Experimental — **use at your own risk.**

Native support for **MakerBot** (Birdwing + legacy/Sailfish) and **UltiMaker** printers: `.makerbot` / `.x3g` / `.ufp` export, network printing with a Device tab (telemetry, camera, controls, global Z-offset), vendor profiles, and a 21-language UI.

### Install
- **Windows:** `…_x64.exe` / `…_arm64.exe` installer, or portable `.zip`
- **macOS:** universal `.dmg`
- **Linux:** `.AppImage` (`chmod +x`)

⚠️ **These binaries are not code-signed.** Windows SmartScreen and macOS Gatekeeper will warn you on first launch — on Windows choose *More info → Run anyway*, on macOS right-click the app → *Open*. This is expected for an independent community build.

### Please test & report
Hardware-verified on the Replicator Z18 and 2X; **all other models are firmware-derived and need real-world testing.** If you own one, please open an issue with your model, OS, and what happened. Native-speaker translation corrections (especially Thai, Vietnamese, Lithuanian, Hungarian) are very welcome.
